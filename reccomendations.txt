Here is the comprehensive action plan to revamp your Mood Board into a fully-fledged Project Showcase with SEO.

### **Phase 1: Database Architecture (Supabase)**
We need to introduce a "Project" entity to group your images.

1. **Create `projects` Table**:
    *   **Fields**:
        *   `id` (UUID, Primary Key)
        *   `title` (Text)
        *   `slug` (Text, Unique) – *Critical for SEO friendly URLs (e.g., /mood-board/modern-kerala-villa)*
        *   `description` (Text/Rich Text) – *For detailed project narratives*
        *   `cover_image` (Text) – *Thumbnail for the main listing page*
        *   `published_at` (Date)
        *   **SEO Fields**: `meta_title`, `meta_description`, `keywords`
        *   *RLS Policies*: Public read access, Admin write access.

2.  **Update `gallery_images` Table**:
    *   **Add Column**: `project_id` (Foreign Key referencing `projects.id`).
    *   **Add Column**: `media_type` (Text, Default: 'image') - *To distinguish between Uploaded Images and Social Embeds*
    *   *Note*: This allows us to assign multiple existing or new images to a specific project.

### **Phase 2: Admin Panel Upgrades**
We need to update the admin interface to manage these projects.

1.  **New Page: Project Management**:
    *   Create a generic "Projects" list view (Create, Edit, Delete).
    *   **Project Form**: Inputs for Title, Slug (auto-generated from title but editable), Description, and SEO tags.
    *   **Cover Image Upload**: Specific uploader for the project thumbnail.

2.  **Enhanced Image Management**:
    *   Update the existing `GalleryImageForm` to include a **"Select Project"** dropdown.
    *   *(Better UX)*: Inside the "Edit Project" screen, add a "Project Gallery" section where you can bulk upload images directly to that project.
    *   **Social Media Integration**: Add a toggle to switch between "Image Upload" and "Social Embed Link".

### **Phase 3: Handling Existing Images & Social Media (Hybrid Strategy)**
We do not want to delete or break your current images.

1.  **The "Orphan" Strategy**:
    *   Any image *without* a Project will continue to appear in a "General Feed" or "Mood Board Stream" at the bottom of the page.
    *   **Migration**: We will build a simple "Organizer" in the Admin Panel to easily assign unlinked images to new projects.

2.  **Social Media Integration**:
    *   **Hybrid Card**: We will upgrade the output to render "Social Cards" for Instagram/Facebook links.
    *   **Embeds**: Use Instagram Embeds to load posts directly, saving storage and keeping content fresh.
    *   **Link Mode**: In the Admin Panel, you can paste a URL instead of uploading a file.

### **Phase 4: Frontend Revamp (The Mood Board)**
Refactoring the user-facing pages to support the new structure.

1.  **Revamp `MoodBoard.tsx` (Main Listing)**:
    *   Change logic to fetch **Projects** instead of raw images.
    *   **UI**: Display a grid of "Project Cards" (Cover Image + Title + Short Excerpt).
    *   **SEO**: Global meta tags for the main portfolio page.

2.  **Create `ProjectDetail.tsx` (New Page)**:
    *   **Route**: `/mood-board/:slug`
    *   **Logic**:
        *   Fetch project details using the `slug`.
        *   Fetch all `gallery_images` linked to this project.
    *   **UI**:
        *   Show Project Title & Description.
        *   Masonry or Grid layout for the project's images mixed with Social Embeds.
    *   **SEO**: **Crucial Step** – Inject the `project.meta_title` and `project.meta_description` into the `<head>` using your `SEO` component.

### **Phase 5: Routing & Navigation**
1.  **Update `App.tsx`**:
    *   Add the dynamic route: `<Route path="/mood-board/:slug" element={<ProjectDetail />} />`

### **Summary of Benefits**
*   **SEO**: Each project gets its own URL (`dplhomestar.com/mood-board/luxury-villa`), allowing Google to index specific projects.
*   **Organization**: Ends the "cluttered stream of images"; groups work logically.
*   **Scalability**: Easy to add new projects without touching code.
*   **Efficiency**: Social Media links save storage and time.
